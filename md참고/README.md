# GAJAGO

Expo React Native + TypeScript version of the GAJAGO travel app prototype.

## Run

```bash
npm install
npx expo start
```

Android targets:

```bash
npx expo start --android
npx expo run:android
```

## Notes

- The app uses React Navigation native stack routing.
- The previous web-only stack was removed from source.
- Map, payment, and live account integrations are placeholders prepared for native API wiring.
